# DevScout — GitHub Profile Finder (Starter)

Responsive GitHub profile explorer built with HTML, CSS and vanilla JavaScript. UI is styled; JavaScript behavior is intentionally left as TODOs.

## Run
1. Extract ZIP and open the folder in VS Code.
2. Open `index.html` in a browser (Live Server recommended).
3. Keep an internet connection and implement TODOs in `script.js`.

## Checklist

## Concepts
`fetch`, `async/await`, JSON, DOM updates, error handling, event listeners and `localStorage`.

GitHub public API is rate-limited for unauthenticated requests.
